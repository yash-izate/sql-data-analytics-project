
# SQL Data Analytics Project

## Overview
This project focuses on performing data analysis using SQL Server. It demonstrates different analytical techniques to extract meaningful insights from structured datasets created in the SQL Data Warehouse project.

The project uses SQL scripts to explore data, analyze trends, calculate business metrics, segment customers, and evaluate product and sales performance.

## Objectives
- Practice SQL-based data analytics.
- Explore datasets and understand their structure.
- Analyze sales, customers, and products.
- Calculate key business metrics and performance indicators.
- Apply advanced SQL techniques, including window functions, CTEs, and subqueries.
- Develop clean, readable, and reusable SQL scripts.

## Dataset
The datasets are obtained from the previous SQL Data Warehouse project and include CSV exports and a SQL Server database backup.

### Data Layers
- **Bronze:** Raw source data.
- **Silver:** Cleaned and transformed data.
- **Gold:** Business-ready dimensional models and reporting datasets.

### Key Datasets
- `gold.dim_customers.csv`
- `gold.dim_products.csv`
- `gold.fact_sales.csv`
- `gold.report_customers.csv`
- `gold.report_products.csv`

## Project Workflow
1. Restore the SQL Server database backup.
2. Inspect database tables, columns, and relationships.
3. Profile datasets and perform data quality checks.
4. Develop SQL scripts for different analytical techniques.
5. Validate query results and interpret findings.
6. Document the analysis and key insights.
